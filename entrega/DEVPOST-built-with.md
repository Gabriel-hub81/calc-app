# Built With — etiquetas para Devpost

Devpost las pide como etiquetas cortas, una por una. Escribe cada renglón y
presiona Enter. Van ordenadas de más a menos importante: las primeras son las
que un juez busca.

```
google-gemini
google-cloud
cloud-run
cloud-scheduler
firestore
node.js
express.js
react
vite
tailwindcss
mathjs
jest
javascript
pwa
web-scraping
```

## Por si el campo es de texto libre

Google Gemini (gemini-3.5-flash, language + vision) · Google Cloud Run ·
Cloud Run Jobs · Cloud Scheduler · Cloud Logging · Cloud Build ·
Firestore · Node.js · Express · React 19 · Vite · Tailwind CSS · mathjs ·
Jest · Supertest · Privy (auth) · PWA / Workbox · SNIIM (Mexican Ministry of
Economy open market data)

## Dos notas

**Solana no va en la lista.** El repositorio incluye un programa de Anchor de
una etapa anterior, pero se decidió sacarlo del pitch: no suma en un concurso
de Gemini, y mencionar cripto sin explicarlo invita preguntas que distraen de
lo que sí califica. Si un juez lo encuentra en el repo, está documentado ahí.

**SNIIM vale la pena mencionarlo aunque no sea un framework.** Es la fuente de
datos de precios de mayoreo de la Secretaría de Economía, y es justo la pieza
que nadie más de la categoría tiene. Si el campo permite texto, que aparezca.
